## 📌 Executive Summary

Every year, over **1.2 million international students and researchers** relocate across borders into mainland China and Asian financial hubs. Upon arrival, they face severe financial friction:

* 🚨 **High-Risk Fraud Traps:** $1.4B lost annually to unverified social-media tuition brokers and illicit peer-to-peer (P2P) currency swaps.
* 💸 **FX Volatility & Hidden Spreads:** Up to 7.8% eroded in bank remittance markups and currency shocks between offer acceptance and tuition day.
* 🏦 **Unbanked Arrival Delays:** 2 to 4 weeks of campus paralysis waiting for police accommodation certificates and branch appointments.
* 📈 **Zero Credit Portability:** International students arrive with blank credit files, locked out of rentals, phone contracts, and financial services.

**Landfall solves this entirely.** It is a white-labelable financial landing operating system that combines a **deterministic regulatory policy gate**, **cryptographic audit logging**, and **Google Gemini Flash AI** to guide newcomers from visa approval to their first central bank credit report.

### 1. 🛡 Scam Shield & Anti-Fraud Signal Engine
* **Instant Risk Classification:** Evaluates suspicious payment messages, agent offers, and Telegram/WeChat links against real regulatory fraud signatures.
* **Deterministic Policy Gates:** Automatically flags **`CRITICAL`** or **`HIGH`** risks for unauthorized escrow agents, private Alipay/WeChat accounts, or suspicious discount schemes.
* **Official Code Citations:** Every advisory cites official Chinese statutes such as `[RB-CN-SCAM-01]` and `[RB-CN-TUI-01]`.

### 2. 🎓 CNAPS Institutional Payee Verification
* **Institutional Whitelist:** Cross-references university receiving accounts against verified China National Advanced Payment System (CNAPS) bank routing codes.
* **T3 Ephemeral Authorization:** Restricts high-value operations behind single-use, 15-minute cryptographic confirmation tokens.
* **Zero Real Money Movement:** Safe, simulated sandbox execution guarantees student funds cannot be directed to unverified third parties.

### 3. 💱 Intelligent Multi-Rail Remittance Comparison & FX Replan
* **Transparent Landed-Cost Engine:** Computes real landed costs across SWIFT Wire, UnionPay Cross-Border, and Digital Wallets (Flywire/WeChat).
* **Multi-Currency Support:** Seamless conversion across **BDT (৳), INR (₹), MYR (RM), USD ($), EUR (€), IDR (Rp), KRW (₩)**, and more.
* **FX Stress Replay & Adaptive Replan:** Models historical market volatility and arrival-week currency shocks (e.g., -8% depreciation). 
* **One-Click Critical Path Rebalance:** Re-optimizes living expenses and suggests dual-tranche tuition settlements with a single click.

### 4. 📄 Digital Document Compliance & Bank Readiness Verification
* **Pre-Arrival Bank Eligibility:** Audits student readiness across China's top tier-1 institutions (**Bank of China, ICBC, China Merchants Bank**).
* **Interactive Document Verification:** Verifies passports, student visas, JW202 admission certs, 24-hour PSB police accommodation slips (`RB-CN-PSB-01`), and real-name SIMs with cryptographic IDs (`DOC-VERIF-...`).
* **Live Bank Matchmaker:** Dynamically identifies the optimal institution based on individual student documentation (e.g., zero-deposit accounts with dorm address proof).

### 5. ⭐ PBOC Credit Reference Pathway
* **Clear 6-Stage Roadmap:** Progresses students from unbanked arrival to pulling their official People's Bank of China (PBOC) Credit Reference Report (`RB-CN-CR-01` to `CR-06`).
* **Prerequisite Enforcement:** Enforces strict compliance logic (e.g., UnionPay activation requires verified account opening; secured credit cards require 3-month payment history).
* **Objective Milestone Meter:** Displays true milestone progress with zero speculative score predictions.

### 6. 🤖 24/7 Regulatory AI Copilot (Google Gemini Flash)
* **Context-Aware Intelligence:** Automatically calibrates to the active student's origin, university, semester budget, and active verified milestones.
* **Dual-Currency Cost Projections:** Explains upcoming outlays (e.g., campus dormitories, health exams, residence permit fees) in both **CNY (¥)** and the student's home currency.
* **Zero Hallucination Guarantee:** Architectural design strictly adheres to *"Model plans & explains; deterministic code decides."*

## 🔒 Enterprise Security & Compliance Architecture

Landfall was engineered to meet the stringent security, auditing, and regulatory requirements of international financial institutions and higher-education governance:

```
Permission Tiers:
  T0 Public Read   — Rulebook lookups, FX scenarios            → Unrestricted
  T1 Plan Engine   — Dependency calculations, critical path    → Automatic
  T2 Draft Engine  — Verification receipts, checklists         → Read-only Draft
  T3 Simulated Pay — Simulated transfers, quota updates        → Requires Ephemeral Token
  T4 Forbidden     — Moving real funds, unverified payees      → Strictly Rejected by Code
```

* 🛡 **Untrusted Taint Tracking:** Raw inputs and external documents are permanently tagged `origin=doc` and cannot trigger arbitrary code or prompt injections.
* 🔗 **Tamper-Evident SHA-256 Ledger:** Every verification, FX replan, token issue, and policy check is appended to a cryptographic hash chain. Any log tampering is immediately detectable via `GET /audit/verify`.
* 📋 **Regulatory SAFE Meter:** Continuously tracks annual inbound foreign exchange against China's State Administration of Foreign Exchange **$50,000 USD/year** threshold (`RB-CN-SAFE-01`).

## ⚡ Quick Start & Demo

### Prerequisites
* Python 3.10+
* Node.js 18+ & npm
* *(Optional)* Google Gemini API Key (system includes full offline deterministic fallback)

### 1. Clone & Setup Backend
```bash
git clone https://github.com/mahadir04/LandFall.git
cd LandFall

# Setup Python virtual environment
python -m venv .venv
.venv\Scripts\activate       # Windows
# source .venv/bin/activate   # macOS / Linux

# Install dependencies
pip install -r requirements.txt

# Start backend server
python -m uvicorn backend.api.main:app --reload --port 8000
```
* Backend API: `http://localhost:8000`
* Swagger Interactive Docs: `http://localhost:8000/docs`

### 2. Setup Frontend
```bash
cd frontend
npm install
npm run dev
```
* Web Dashboard: `http://localhost:5173`
